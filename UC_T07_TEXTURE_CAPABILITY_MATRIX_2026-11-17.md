# UC-T07-01 — Texture Graph capability and ownership matrix

[x] Source comparison complete. Later operation implementations, shader/graphics acceptance and phone measurements remain their own tasks.

Target: Unity **6000.5.2f1**, installed URP **17.5.0**. Existing discovery is `NodeCatalog`, with `GraphDomainRules` admitting the texture family and shared field/utility nodes. The actual base type is `TextureNode` in `TextureNodeBase.cs`. The seven concrete-node files under `Core/Runtime/Nodes/TextureGraph/` declare **35 concrete nodes**. Domain admission does not turn their material descriptors into image pixels or shader programs.

The inspected production path is `TextureNode` → typed products/ports → `ShaderOutputNode`/`OutputBag` → `UCTextureGraphApplier`, with the existing accepted-world bindings and explicit Texture Graph Run/Apply. Shared `CreatorNode`/`ModifierNode`, combiners and utilities retain their existing field evaluation; a `Matrix` is one float per sample, `Color` one RGBA constant, and `Scalar` one constant float.

Public reference: [Epic Texture Graph node reference](https://dev.epicgames.com/documentation/en-us/unreal-engine/texture-graph-node-reference-in-unreal-engine), retrieved **2026-11-17, HTTP 200**. Compact headings/excerpts and decoded UTF-8 response SHA-256 are `.work/UC_T07_Epic_node_reference_20261117.json`, hash `51A3E0996197B4720B977CD48AF63848BB2F4DD82B9B79D6589B525E36BF7BCD`. This is a capability reference, not an exact Unreal 5.8 contract or a complete material/GPU implementation study. No engine source or third-party asset is imported; the equations/code will be authored independently. Any later source/asset import needs its own licence/provenance check.

Cost descriptions below are design estimates, not measured UC timings. One 1,024² float RGBA buffer occupies **16 MiB**, one scalar plane **4 MiB**; input, output and scratch buffers add separately. All new bakes must use the existing memory admission/cancellation owners. Parameter descriptor changes need bounded work proportional to parameter count; shader pixel cost depends on actual samples/branches and requires graphics/device evidence.

Adopted ideas: distinguish surface/vertex stage data; treat base colour as reflectance without baked specular illumination; keep metallic/roughness/normal/AO/emission/opacity channels explicit; use albedo alpha for clipping only when explicitly requested and preserve a separate smoothness source. Existing fixed TerrainLit features and validated scalar/colour/vector expressions form the supported shader workflow; arbitrary vertex/compute generation and transparent terrain remain unsupported and diagnosed. Eight existing feature keywords bound the feature matrix to 256 combinations before URP lighting/platform variants. Added layer emission/AO/opacity use values rather than new texture resources; opacity alpha reuses existing layer samplers and every depth/shadow pass shares its projection. Actual compiler/device/rendered costs remain Topic 7 acceptance, not estimates certified by these references.
